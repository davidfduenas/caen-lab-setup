## His procedure (from his README)

He builds an **Apptainer** (formerly Singularity) container that contains the CAEN libraries and ROOT.

1. Install Apptainer and Git. The CAEN digitizer can be connected, but it is optional for compiling and testing.
2. Clone his repository:
   ```bash
   git clone https://github.com/BrunoGelli/Legacy-AmBE_DAQ_DQM.git
   cd Legacy-AmBE_DAQ_DQM
   ```
3. Place **all CAEN and ROOT tarballs** inside the `libraries/` folder.
4. Build the container (`--fakeroot` is needed if you do not have root privileges):
   ```bash
   apptainer build --fakeroot daq_container.sif Singularity.def
   ```
   `Singularity.def` starts from `ubuntu22.04-base.sif`, which is built from `Singularity.base.def` (Ubuntu 22.04 with `g++`, `build-essential`, `libusb-1.0-0-dev`, `libtbb`, `cmake` and other packages).
5. Open a shell in the container, with the ROOT environment loaded:
   ```bash
   apptainer shell daq_container.sif
   ```
6. Compile inside the container (his command, for his `daq_code/main.cpp`):
   ```bash
   g++ -o my_daq daq_code/main.cpp -lCAENDigitizer -lCAENComm `root-config --cflags --libs` -lpthread -std=c++17
   ```

## Using this lab's DAQ with his container

The lab's DAQ program is in [DAQ_Caen](https://github.com/davidfduenas/DAQ_Caen). Apptainer shares your home folder and the working directory with the container by default, so from the `DAQ_Caen` folder you can run:

```bash
apptainer shell /path/to/Legacy-AmBE_DAQ_DQM/daq_container.sif
```

and compile with his command, using this lab's source file (this substitution is not from his README and has not been tested):

```bash
g++ -o daq_threshold_v1.0.0 daq_threshold_v1.0.0.cpp -lCAENDigitizer -lCAENComm `root-config --cflags --libs` -lpthread -std=c++17
```

Then run the DAQ as described in `DAQ_Caen/SETUP.md`, section 8. His container does not contain `tmux`, so the tmux launchers (`bin/hv-session`, `bin/daq-session`) are for the native install. In the container, run the commands directly in the shell.
