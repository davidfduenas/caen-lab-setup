# InfluxDB and Grafana with Docker Compose (optional)

This is an alternative to the InfluxDB and Grafana installation done by `install.sh`. It is not related to the CAEN libraries or the DAQ container, which follow Bruno's instructions (see [CONTAINER.md](CONTAINER.md)).

| Service | What it is |
|---|---|
| `influxdb` | InfluxDB 1.8, database `NOvA_DTG_CAEN` created automatically |
| `grafana` | Grafana, with the InfluxDB data source already configured |

```bash
docker compose up -d      # start both
docker compose down       # stop, keeping the data
docker compose down -v    # stop and delete the data
```

- Grafana: <http://localhost:3000>, login `admin` / `admin` (change it at first login). The InfluxDB data source is already set up.
- InfluxDB: `localhost:8086`, reachable from this machine only. The lab scripts use `127.0.0.1:8086`, database `NOvA_DTG_CAEN`, which matches.
- If you change the database name, change `INFLUXDB_DB` in `docker-compose.yml` and `database:` in `docker/grafana/provisioning/datasources/influxdb.yml`.

Tested: both services start, the database is created, the Grafana data source is provisioned, and a point written to InfluxDB is read back through Grafana.
