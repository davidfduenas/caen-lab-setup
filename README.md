# caen-lab-setup

Setup for a CAEN HV power supply (DT5471P) and a CAEN DT5730S digitizer. There are **two independent ways** to set it up. Pick one and follow only its guide:

| | Guide | What it is |
|---|---|---|
| **A. Install directly** | [NATIVE.md](NATIVE.md) | A script installs everything on a Debian/Ubuntu computer. |
| **B. Docker** | [DOCKER.md](DOCKER.md) | InfluxDB, Grafana and the DAQ tools run in containers. |

## What is in this repository

It bundles three repositories as git submodules:

| Submodule | Fork of | Purpose |
|---|---|---|
| [DAQ_Caen](https://github.com/davidfduenas/DAQ_Caen) | [BrunoGelli/DAQ_Caen](https://github.com/BrunoGelli/DAQ_Caen) | Digitizer DAQ, temperature monitor, waveform viewer |
| [caen-dt5471p-monitor](https://github.com/davidfduenas/caen-dt5471p-monitor) | [BrunoGelli/caen-dt5533e-monitor](https://github.com/BrunoGelli/caen-dt5533e-monitor) | HV supply control and InfluxDB logging |
| [tmuxsessions](https://github.com/davidfduenas/tmuxsessions) | none (original) | tmux startup scripts for both |

The CAEN libraries the DAQ needs are included in `docker/caen/caen-installed.tgz`. They are CAEN's files: see [docker/caen/NOTICE.md](docker/caen/NOTICE.md).
